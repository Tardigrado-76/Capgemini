# 🔍 SKILLS_REGISTRY.md — SEMANTIC DISCOVERY PROTOCOL
## Catálogo de Habilidades del Protocolo de Divulgación Progresiva

> **Sistema:** Semantic Discovery Protocol (:8510)  
> **Misión:** Implementar el modelo canónico Tier-0 que reduce el consumo de tokens en un 85-94% mediante divulgación progresiva, enrutamiento inteligente y síntesis JIT de recursos web.

---

## Matriz de Skills

| Skill | Categoría | Rol en el Protocolo SDP |
| :--- | :--- | :--- |
| `orcarouter-lite` | Asignación de Tokens | Router in-process dinámico que asigna complejidad de prompt a modelo óptimo (Tier-0 Fast vs Tier-3 Reasoning) sin proxy externo. |
| `orcarouter-mcp` | MCP de Enrutamiento | Servidor MCP nativo para enrutamiento inteligente multi-modelo con control de latencia y coste desde el contexto de agente. |
| `crawl4ai` | Ingesta Web JIT | Encapsulamiento de recursos web en manifiestos Tier-0 con resúmenes semánticos e hidratación bajo demanda. |
| `scrapling` | Extracción Resiliente | Scraping adaptativo con anti-detección avanzada para portales regulatorios y fuentes de datos protegidas. |
| `mcp-builder` | Protocolo MCP | Scaffolding y validación de herramientas nativas MCP a partir de specs OpenAPI/REST. |
| `hyper-extract` | Ingesta Estructurada | Parseo determinista de documentos (PDF, Word, Web) a modelos Pydantic con cero overhead de alucinación. |
| `n8n-mcp` | Automatización | Integración de flujos n8n como herramientas nativas MCP para orquestación de pipelines de datos. |
| `changedetection` | Monitorización | Detección de cambios en fuentes de datos canónicas para invalidación del caché Tier-0. |
| `systematic-debugging` | Diagnóstico | Investigación de degradaciones en ratio de compresión de tokens y fallos de síntesis JIT. |
| `verification-before-completion` | Rigor Epistémico | Comprobación de la reducción real de tokens antes de certificar eficiencia del protocolo. |
