# 🧪 SKILLS_REGISTRY.md — AGENT EVALUATION FRAMEWORK (TAU-bench & GAIA)
## Catálogo de Habilidades del Marco de Evaluación Adversarial

> **Sistema:** Agent Evaluation Framework (:8509)  
> **Misión:** Certificación adversarial de agentes IA mediante escenarios multi-turno, benchmarks de investigación profunda y evaluación de latencia de voz.

---

## Matriz de Skills

| Skill | Categoría | Rol en el Framework de Evaluación |
| :--- | :--- | :--- |
| `gstack` | Metodología Benchmark | Marco estructurado para evaluar capacidades en tareas reales con métricas reproducibles (EARS Index). |
| `agenticseek` | Deep Research | Benchmarking adversarial de razonamiento multi-salto, filtrado de ruido informativo y citas verificables. |
| `nemo-voicechat` | Latencia de Voz | Medición del ciclo conversacional de voz (<600ms), TTFT, VAD barge-in y calidad ASR/TTS (NeMo). |
| `systematic-debugging` | Diagnóstico | Investigación estructurada de regresiones en métricas de evaluación y comportamientos inesperados. |
| `sentry` | Observabilidad | Trazado de ejecuciones de agente y captura de excepciones durante escenarios adversariales. |
| `elasticsearch` | Análisis de Resultados | Indexación y consulta de historial de ejecuciones TAU-bench y métricas GAIA para análisis comparativo. |
| `verification-before-completion` | Rigor Epistémico | Validación empírica de métricas antes de emitir certificados de aptitud de agente. |
| `litellm` | Proxy Multi-Modelo | Evaluación comparativa de múltiples LLMs bajo las mismas condiciones de benchmark. |
