## Matriz de Skills

| Skill | Categoría | Rol en el Módulo de Compliance |
| :--- | :--- | :--- |
| `changedetection` | Vigilancia Regulatoria | Monitorización continua de BOE, DOUE, EUR-Lex y portales regulatorios para detectar enmiendas y activar re-auditorías en caliente. |
| `anything-llm` | Ground Truth RAG | Consultas semánticas a colecciones documentales legales privadas (DORA, NIS2, CCN-STIC) sin alucinaciones ni fugas de datos. |
| `gdpr-compliance` | Privacidad & Datos | Auditoría de datos personales, gestión de cookies, derecho al olvido y retención privacy-by-design. |
| `cybersec-assessment` | Ciberseguridad TIC | Evaluación de postura de ciberseguridad, WAF, IAM, OWASP y controles NIS2/DORA/ENS. |
| `lca-carbon-footprint` | Sostenibilidad ESG | Cálculo de huella de carbono ISO 14067 y generación de Pasaportes Digitales de Producto (DPP). |
| `echa-compliance` | Cumplimiento Químico | Consulta de normativas REACH, listas de sustancias SVHC y restricciones de uso de materiales. |
| `elasticsearch` | Observabilidad Legal | Indexación y búsqueda de logs de auditoría para trazabilidad judicial de eventos de cumplimiento. |
| `sentry` | Trazabilidad de Incidentes | Captura de stacktraces y eventos de violación normativa para análisis de causa raíz. |
| `systematic-debugging` | Diagnóstico | Investigación estructurada de fallos en sondas de cumplimiento y alertas de deriva. |
| `verification-before-completion` | Rigor Epistémico | Comprobación empírica obligatoria antes de emitir cualquier certificado de conformidad. |
